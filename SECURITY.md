# Política de segurança

Se você encontrou uma vulnerabilidade no servidor MCP da Vend.AI ou neste plugin, **não abra uma
issue pública**. Use o relato privado do GitHub (aba *Security → Report a vulnerability* deste
repositório). Responderemos o mais rápido possível.

Este repositório não contém segredos: a conexão usa login (OAuth) e nenhuma chave é gravada aqui.
